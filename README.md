# SAM DE TRACKER Website

Stage 1: homepage for SAM DE TRACKER, built with HTML5, CSS3 and vanilla JavaScript.

This project intentionally uses one `index.html` file. All homepage navigation uses anchor links to sections within the page. Additional website pages should not be added until the corresponding development stage is requested.

## Website files

- `index.html` — Homepage
- `about.html` — About Us
- `services.html` — Services overview
- `contact.html` — Contact page
- Individual service detail pages:
  - `car-gps-tracking.html`
  - `fleet-management.html`
  - `commercial-vehicle-tracking.html`
  - `motorcycle-tricycle-tracking.html`
  - `vehicle-security-support.html`
  - `tracking-device-installation.html`

## Open the website

Open `index.html` directly in a browser, or serve the folder with any local static server.

## Replace images and logo

- Replace `images/logo.svg` with the final company logo (you may also use a PNG).
- Replace `images/hero-car.jpg` with the final hero vehicle image.
- Replace `images/about-car.jpg` and `images/fleet-truck.jpg` as needed.

All service descriptions and WhatsApp enquiry links are ready for business-owner confirmation before launch.
